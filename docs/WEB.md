# The web frontend

Svelte 5 runes + Vite, TypeScript end to end.

## Shape

ONE shell: a sidebar (persona tabs + the active workflow) beside a
PERSISTENT map canvas that never remounts on a persona switch;
persona-owned layers DERIVE from app.persona. The map is A VIEW,
not a fixture: data screens hide it and the rail takes the full
width (`.map-side.hidden`; entity and service-type screens frame
things on it). Data sources (feed, rt, streets, population layer)
is a MODAL, not a floating panel. The Planner persona is a
WORKSPACE of screens with a back stack, ROOTED AT SERVICE PLANS
(the chain: in force / upcoming / superseded, fork = the
service-change workflow); below that the network overview
(per-service-type analysis — planners design types, not calendar
dates) and drill-downs per entity. There is no planner drawer.

## File ownership

- `src/wasm.ts` wraps the artifact (GtfsHandle + every op);
  components never see the ABI.
- `src/capabilities.svelte.ts` is the bus resolver — manifest
  validation, demand-driven load, byte verification against pinned
  hashes, per-capability degradation, and the IMMUTABLE document
  store (every version hash-chained by produced_by; `current` is a
  pointer; migrations move it forward, rollback moves it back;
  IndexedDB-persisted). CapabilityDemo.svelte is the visible story
  (assembly, hash handoff, degraded state, migrate/rollback) in the
  DataSources modal.
- `src/planner.ts` owns authoring mutations (clone → edit →
  replace → revalidate) and the screen stack.
- `src/state.svelte.ts` owns the documents (edit document, plan
  set — both IndexedDB-persisted, wholesale-replaced).
- MapView owns all map state (`window.__map`).

## Frontend conventions and gotchas

- **TypeScript end to end** — every type that crosses the wasm
  boundary is GENERATED (`just types`, refreshed by `just test`):
  ts-rs derives on the model crates emit `web/src/types/*.ts`;
  commit the diff like any artifact. The TS contract IS the
  artifact's contract. Plain `cargo test` scatters bindings into
  `crates/*/bindings` — always set `TS_RS_EXPORT_DIR` (the justfile
  does). `npm run typecheck` (svelte-check, wired into `just
  build`) gates all of src/ — components carry `lang="ts"`, the
  runes modules are `.svelte.ts`. TypeScript is pinned to 6.x:
  svelte-check does not yet accept TS 7.
- Response FIELD names from the artifact are snake_case (the serde
  default) — a TS cast with a camelCase field name compiles and
  typechecks fine but reads `undefined` at runtime (this shipped
  once: `streets_id` vs `streetsId`).
- **Svelte `$state` proxies are not structured-cloneable** — persist
  plain data (`$state.raw`, wholesale replacement), never proxies.
- **await arrayBuffer() before crossing into wasm** — a Promise in
  a `&[u8]` slot decodes as zero bytes, silently.
- MapLibre's `LngLatBounds.extend` parses a bare array-of-arrays as
  the `[[west, south], [east, north]]` form and silently ignores
  the rest — extend one point at a time (`boundsOf` in MapView).
- e2e fixture changes: edit `web/e2e/make_fixtures.py`, run `just
  fixtures`; the rt protobuf fixture is generated by `cargo run -p
  transit-rt --example encode_sample`.
- Playwright e2e runs its own server on :8081 with
  `reuseExistingServer: false` (hermetic: a shared server carries a
  live edit document, and test records must not land in a dev
  server). Port 8080 is the dev-server default — check `ss -tlnp`
  before starting one.
