# D-250 — Which distance do the libraries share?

Topic: The libraries.
State: Decided.
Answer: 2026-11-24 — "go with haversine": the great-circle distance on
a sphere of the mean earth radius (6,371,000 m), the one the stop
directory, the stops, and the coverage analysis already used. One
library holds it, and every library that reports or compares a
distance uses it.
Pinned by: `crates/transit-geo/tests/distance_law_test.rs` (the
distance's laws, and the local frame's agreement with it at street
scale); the streets oracles in `crates/transit-streets/tests/`, which
write the same metric out independently. The reasoning is in
`docs/architecture/crates/transit-geo.md` ("Why").
Blocks: nothing.
